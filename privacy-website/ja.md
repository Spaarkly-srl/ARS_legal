## 2. データ、目的および法的根拠

**閲覧およびセキュリティ。** 本サイトの動作、セキュリティおよび診断のために、IP アドレス、日時、リクエストされたページ、応答コード、ブラウザに関する情報を取り扱います。法的根拠は、本サイトの適正かつ安全な動作を確保することに関する当社の正当な利益です（GDPR 第6条第1項(f)）。

**利用統計（任意）。** お客様の同意がある場合にのみ、訪問とインタラクションを計測するために **Google Analytics 4** を使用します。その際には、Cookie の識別子、デバイスおよびブラウザのデータ、閲覧したページ、流入元、おおよその位置を用います。欧州からのトラフィックの IP アドレスは位置の推定に使用されますが、Google はこれを記録も保存もしません。Google Signals、広告機能、リマーケティングはいずれも使用しません。法的根拠は同意です（GDPR 第6条第1項(a)）。同意を拒否しても本サイトの利用に影響はなく、フッターの「**クッキー設定**」から撤回することもできます。

**Cookie に関する選択。** ランダムな識別子、日時、ポリシーのバージョンおよび言語、カテゴリ、ならびに行われた選択を記録します。選択ログには IP アドレスも user-agent も記録しません。これは、GDPR 第5条第2項および第7条第1項に基づく義務の履行として、同意を証明するために行うものです（第6条第1項(c)）。その他の選択については、お客様の設定を尊重し、記録に残すことに関する正当な利益が根拠となります（第6条第1項(f)）。

**デモおよびトライアルのリクエスト。** リクエストを処理し、お客様に折り返しご連絡するために、氏名、会社名および業態、国、業務用メールアドレス、電話番号、役職、カタログの規模、関心のある製品、ならびにメッセージ（ご記入の場合）を収集します。また、プライバシーポリシーおよび利用規約を読んだ旨の表明を記録に残すため、その日時、バージョンおよび言語も記録します。

**24時間**有効な確認リンクをお送りします。確認が完了して初めて、リクエストは CRM に登録され、対応が開始されます。確認されなかったリクエストは、不正利用、詐欺の試みまたは不正競争行為を検知・記録し、当社の権利を保護するため（その後の当局からの要請に関連する場合を含みます）にのみ保存し、営業目的で改めてご連絡することはありません。リクエストをしていないのに確認の連絡を受け取った場合は、それを無視し、**privacy@spaarkly.com** までお知らせいただくことができます。

法的根拠は、お客様がご自身のために行動する場合はお客様の要求に基づいて講じられる契約前の措置の実施（GDPR 第6条第1項(b)）、またはお客様が代表する企業のリクエストを処理することに関する正当な利益（第6条第1項(f)）です。不正利用、詐欺および不正競争を防止・記録すること、ならびになされた表明を記録に残すことの根拠は、権利の保護に関する当社の正当な利益です（第6条第1項(f)）。当局への義務的な提供は、適用される法的義務に基づきます（第6条第1項(c)）。

必須項目はフォームに表示されています。必須項目がない場合、リクエストを処理することはできません。メッセージは任意です。**ARShades Studio** でのトライアルの有効化は、同プラットフォームの利用規約およびプライバシーポリシーに従います。

## 3. データの保存期間

| データ | 保存期間 |
|---|---|
| 閲覧およびセキュリティのログ | 原則として記録から30日。これを超える保存は、インシデントの究明または権利の保護のためにのみ、必要な期間に限ります |
| Google Analytics 4 のユーザーデータおよびイベントデータ | 最長14か月。匿名化された統計は、これより長く保存される場合があります |
| Cookie に関する選択のログ | 各記録から最長26か月 |
| デバイス上の Cookie に関する選択（`ars_consent`） | 12か月 |
| 確認されなかったリクエスト | 送信から12か月、その後削除。具体的な調査もしくは紛争、または当局からの要請がある場合は、関連するデータに限り、必要な期間または法律に定める期間、この期間を超えて保存します |
| 確認されたリクエストおよび関連する連絡 | リクエストに関するお客様との最後のやり取りから24か月。契約関係が成立した場合は、当該サービスのプライバシーポリシーに定める保存期間が適用されます |
| ZeptoMail におけるメールの配信ログ | 原則として送信から60日 |
